1Attaché — an iOS remote for omp · 3 directions × 7 surfaces
Attaché working name — the aide that carries omp's business while you're away. Alternates: Skipper, Waypoint.
A native iOS GUI for driving omp remotely — not a terminal. Everything omp surfaces in the TUI has a first-class home here: compact tool cards you tap to expand (the Ctrl+O gesture), advisor commentary as a distinct inline voice, approvals answered from the stream or the lock screen, subagents as live tiles you can steer. Demo session throughout: fixing a memory leak in a Go image pipeline (pixeld), real code + diffs.
OMP CAPABILITY → WHERE IT LIVES
sessions · resume / branch / share → 01 home, header menu
turn stream, compact cards (Ctrl+O) → 02 tap-to-expand cards
advisor role, can interrupt → 02 inline voice blocks
approvals (destructive tools) → 02 inline · 04 queue · 07 push
subagents, steer, agent:// transcripts → 03 live tiles + sheet
plan / goal / loop modes → 02 composer mode switch
context + snapcompact + cost → 02/01 slim meter
model roles ×8 + thinking levels → 05 roles table
fallback chains → 05 chain card
rules (8 formats) / skills / MCP / extensions → 05 rows
hindsight memory → 05 toggle
hashline edits → 02 diff cards, hash badge
LSP diagnostics → 02 edit-card footer chip
remote reach (daemon · tailscale · relay) → 06 pairing
